# Little Works site

Static privacy and support pages for Little Works iPhone apps, deployed on Vercel.

- `teleprompter/privacy/` — Teleprompter privacy policy (App Store Connect "Privacy Policy URL")
- `teleprompter/support/` — Teleprompter support (App Store Connect "Support URL")
- Support requests come in through the issue form in `.github/ISSUE_TEMPLATE/support.yml`.

Add a folder per app and list it on `index.html`. Deploy with `vercel deploy --prod`.
